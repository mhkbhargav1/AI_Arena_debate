# 🤖 AI Debate Arena

> An interactive web application where AI models debate topics in real-time, built with Python and modern web technologies.

---

## 🚀 Features
* **Real-Time Debate Stream:** Watch AIs argue different sides of a topic dynamically.
* **Clean UI:** Responsive web interface built with custom HTML, CSS, and JavaScript.
* **Modular Backend:** Python application structure for smooth API handling and orchestration.

---

## 🛠️ Tech Stack
* **Backend:** Python, Flask/FastAPI
* **Frontend:** HTML5, CSS3, JavaScript
* **APIs / Integrations:** LLM Providers
